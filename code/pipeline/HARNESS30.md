## 메모리 규율 (2026-08-24 추가 — 실행환경 크래시 대응)

`load()`가 전체 패널 pivot 5종(Ev/Hv/Sv/Av/NSv)을 올리므로 그것만으로 피크 RSS 약 2GB다.
경로 스크립트는 그 위에 설계행렬을 얹으므로 다음을 지킨다.

1. **이산 공변량 모형은 셀로 접는다.** 기업-월 개별관측 대신 (이벤트×처치×사후×버킷) 셀 +
   grouped binomial. 계수 동일, 행 수 10배 감소. (I-02 실측: 48,853 → 4,686, 계수 +0.1478 불변)
2. **설계행렬은 float32**, 고정블록(FE·더미)은 **한 번만 만들어 재사용**하고 관심변수만 교체한다.
3. 적합 직후 `del X, r; gc.collect()`. 대형 중간객체(`rec`, 원 DataFrame)는 쓰고 나면 즉시 `del`.
4. `pd.get_dummies` + `concat` + `add_constant` + `.values` 연쇄는 복사본을 4~5개 만든다 — 금지.
   numpy `np.hstack`으로 직접 조립.
5. 장시간 실행은 `/usr/bin/time -v`로 **Maximum resident set size를 로그에 남긴다.**
