## 현재까지 조립되는 경제 모형 (잠정, 경로 완료 시 갱신)

> 아래는 **완료 7경로가 지지하는 범위**의 서술이며, 미완 23경로가 뒤집을 수 있다.

**사실.** PE 투자 후 대상기업의 월별 채용 hazard가 16% 오른다(I-02). 이 상승은 거의 전부
**외연마진** — 뽑는 달의 수가 늘어난 것이지 한 번에 더 많이 뽑는 것이 아니다(기존 §22–23, 71%).
순고용과 이직은 움직이지 않는다(기존 §14 계열).

**메커니즘.** 두 후보가 서로 다른 예측을 하고 자료가 갈랐다(I-03).
조정 고정비용이 내려갔다면 기업이 채용을 개시하는 **임계 갭**이 낮아져야 하는데 **불변**이다
(평균 trigger gap DiD −0.0013, 비유의). 대신 **갭을 방치하는 최악의 폭**이 유의하게 줄어든다
(최대도달갭 −0.0258 [−0.0416, −0.0095]). 즉 **조정 기술이 싸진 것이 아니라, 조정하지 못하고
넘어가던 국면이 사라졌다.** 이는 가격(비용)이 아니라 **주의·감시(attention/monitoring)** 의 변화다.

**경계조건 두 개가 이 해석을 검증한다.**
1. **대상 의존적**: 효과는 사전에 관성이 심했던 기업에만 나타나고, 이미 매달 뽑던 기업에서는 0이다
   (I-25, T3 −0.1110 ✓ vs T1 −0.0152 ✗, 삼중교호 유의). *제거할 비주의가 있어야 제거된다.*
2. **딜 구조 비의존적**: 다수지분 바이아웃과 소수지분 성장투자가 **같은 크기**의 효과를 낸다
   (I-16, 차이 −0.0011, 등가성 성립). *통제권이 아니라 관여가 작동한다*는 가설과 정합하나
   **이사회·정보권 자료가 없어 미검증**이다.

**따라서 잠정 명제.**
> PE의 노동 효과는 고용 수준이 아니라 **조정 빈도**에 있고, 그 원천은 조정비용 인하가 아니라
> **비주의의 제거**이며, 크기는 **딜의 구조가 아니라 대상 기업이 사전에 무엇을 방치하고 있었는가**로
> 결정된다. 이 대상은 연간 자료에서 정의상 관측되지 않는다(I-01).

**아직 못 하는 말.** (a) 이것이 좋은 일인지 — 생산성·실적 앵커 없음(**I-04 필요**).
(b) 소유주가 실제로 무엇을 했는지 — 관여의 직접 증거 없음(**I-17 필요**).
(c) 소유주가 떠나면 되돌아오는지 — **I-05 실행 완료(2026-08-24), 판별 불가로 확정**: exit 13건의 sum CI
[−0.212, +0.034]가 완전가역(0)과 비가역(−0.0715)을 모두 포함한다. 이 경로는 자료 한계로 닫혔다.
(b) 관여의 직접 증거 — **I-17 실행 완료, GP 성분 미검출**(순열 p 0.26/0.28). 이사회 자료 부재로 이 경로도 닫혔다.
**평균회귀 위협은 I-31 이 제거했다** (고관성 위약 −0.002 [−0.058, +0.044] vs 실제 −0.111, RI p<0.001).
**(a) 실적 앵커 — I-04 실행 완료(3판)**: 부가가치 +8%✓, **VA/인원 등가성 성립(δ=0.10) 전 지평**,
자산 +23%✓ → **비례 확장이지 효율 개선이 아니다.** 효율 개선 주장 금지.
**사적 정보 시점선택 위협 — I-15 가 반증**(교호 HR 1.25 [1.03, 1.52], 선택 예측과 역방향).
→ 남은 한계는 **사전추세 M̄=0.658** 과 **not-yet-treated 검정력** 둘뿐이며, 정직한 한계로 서술 가능하다.
